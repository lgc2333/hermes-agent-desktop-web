## 坑: Node 26 实验性 webstorage 致桥测 74 失败(非回归)

- 现象:vitest 桥测(registry/gateway 等)74 失败,`window.localStorage` undefined,
  Node 报 `ExperimentalWarning: localStorage is not available because
--localstorage-file was not provided`
- 根因:**本机 Node v26.5.1**(远超项目 engines node>=22.22)自带实验性 web
  storage 全局,未启用时把 jsdom 的 `window.localStorage` 影子成 undefined。
  bridge 测试不加载 vendor,与上游同步无关;lockfile 变化(nanostores 1.4.0→1.4.2、
  +blobatar/driver.js)与 jsdom 无关。
- 验证:加 `NODE_OPTIONS=--localstorage-file=/tmp/ls.json` 后 102 全过 → 证实纯环境问题。
- **CI 未受影响**:ci.yml 钉 Node 22,Nod e22 无此 webstorage 全局,桥测照常绿。
- 教训:本机是 Node 26,跑桥测须带 `--localstorage-file`;勿因此改测试/源码。

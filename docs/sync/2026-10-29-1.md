## 桥面契约变化（global.d.ts）与处理

```diff

```

| 上游变化                                           | 类型       | 本仓处理                                                                                                                                                                  |
| -------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `touchBackend` / `getPoolLimits` / `setPoolLimits` | 必填面删除 | 桥层删除三面（`adapter.ts` 字面量成员 + `gateway/index.ts#touchBackend` + `index.test.ts` 断言），否则 excess property 报错                                               |
| `getConnection` / `getConnectionFor` 的 `priority` | 参数撤销   | `gateway/index.ts#getConnectionFor` 参数类型删 `priority?`；渲染层已无调用点                                                                                              |
| `onPoolBackendRetiring?`                           | 可选面删除 | 本仓本就未实现                                                                                                                                                            |
| `getPluginWsUrl?`                                  | 可选面新增 | **不实现**：只在 `connection.authMode === 'native'` 的本机网关上取一次性 URL，Web 连接恒为 token/oauth → 走原有 `ws://…/api/plugins/<id>?token=` 分支，行为不变           |
| `saveTextFileAs?`                                  | 可选面新增 | **实现**（浏览器等价）：`gateway/download.ts#saveTextFileAs` 把内容交给下载管理器，返回 `{ saved: true, path: <文件名> }`；`/save` 因此可用（此前落到 "saveUnsupported"） |
| `preparedSubmissions?`                             | 可选组回归 | **不实现**：上游对缺失情形有 localStorage 回退（`prepared-submissions.ts`），桌面 main 进程只是可选加速；Group Send 在 Web 走回退路径                                     |
| `authMode: 'native'`                               | 字面量扩充 | 无桥面改动（Web 记录恒 token/oauth）；渲染层 native 分支不进入                                                                                                            |

机械比对（解析 `declare global` 的 `hermesDesktop` 顶层成员，164 个 / 必填 73 个）：桥层
`const bridge: Bridge` 字面量 **无多余成员、无缺失必填成员**（唯一「缺失」是 shorthand 写法
`readFileDataUrl,` 被脚本正则漏判，`pnpm typecheck` 亦兜底）。未实现的可选面清单见 §4/§5

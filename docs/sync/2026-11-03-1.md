## 上游性质：又一个 patch release（策展说明仍推迟）

release 自述：v0.22.5 以来 **776 个 PR**、3,448 个非 merge 提交，兼容性修复与
功能混装，**完整策展说明随 v0.23.0 发布**。与本仓最相关的一条结构性变化：

- 上游把「浏览器托管的 Desktop」做成一等形态（`src/lib/browser-desktop-bridge*.ts`、
  `browser-transport.ts`、`browser-launch-session.ts`、`lib/browser-files.ts`、
  `lib/browser-connection.ts`）：gateway 自己派发 Webapp，渲染层经 `browserBootstrap`
  注入的连接信息直连同一监听器。**本仓的定位不变**（无状态代理 + 浏览器侧凭证，
  ADR-0016/0023），但这些文件是本轮桥面新增表面的来源，也顺带把「穷尽实现
  `window.hermesDesktop` 的对象字面量」带进了 vendor —— 直接影响我们的补丁写法（见下）。

其余净变化基本是渲染层与 Electron 主进程（终端持久化/重连、插件文件授权、
NVIDIA EGL 恢复、更新事务、spellcheck 词典等），无新的必填桥面。

## 上游性质：minor 大版本

release note 是 v0.22.0 → v0.23.0 的全量策展说明（~1950 PR），相对我们的增量只是
v0.22.7 之后两天的改动。与 Web 端口相关的两条主线：

1. 上游自己发布了 **Webapp**（由 gateway 直出桌面渲染层，`webapp.enabled` 开关，
   默认关）。与本仓库端口并行存在，互不引用。
2. 「一个 gateway 拥有所有会话」、Desktop 多机并存、Group Chat 自路由等，
   均走 gateway REST/RPC，代理透传即可。
